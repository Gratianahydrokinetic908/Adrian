## 🔍 How It Works

The program sits between your AI agent and the external tools it uses. It checks every incoming instruction. If an instruction attempts to bypass safety rules or perform unauthorized tasks, the software blocks it.

It protects your system in three ways:

1. **Prompt Injection Defense:** It identifies and filters text meant to trick your AI into misbehaving.
2. **Action Validation:** It reviews what the AI intends to do before the command executes.
3. **Policy Control:** It ensures the agent stays within the boundaries you define.
